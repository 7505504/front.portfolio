# Caio Andrade · Portfolio V2

Modern bilingual portfolio focused on backend engineering, payment integrations, distributed systems, and practical AI-assisted development.

## Requirements
- Node.js 22 or newer
- npm

## Run locally
Clone the repository, switch to the V2 branch, install dependencies, and start the development server:

```bash
git clone https://github.com/7505504/front.portfolio.git
cd front.portfolio
git switch feat/portfolio-v2
npm install
npm run dev
```

Visit http://localhost:3000/en (English) or http://localhost:3000/pt-br (Português).

## Validation
```bash
npm run typecheck
npm run lint
npm run build
npm run start
```

## Publishing
Keep the original `main` branch intact. Review and test this V2 branch first. Configure a Vercel preview deployment for this branch and merge to `main` only after approval.
